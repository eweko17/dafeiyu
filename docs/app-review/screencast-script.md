# 螢幕錄影腳本（2–3 分鐘）

Meta 審核員看影片的時間很短，重點是「清楚看到你怎麼用、用了多少、有沒有濫用」。

## 事前

- 用一個乾淨的瀏覽器視窗（無痕模式），只開 Threads 與 Meta 後台。
- 先把大肥魚的 token 設好，確認 `doctor` 正常。
- 準備 2–3 個會出現在關鍵字搜尋的公開貼文（例如搜 `AI` 或 `白飯`）。
- **權限還沒通過時，搜尋只會回你自己的貼文**，這是 Meta 的規定。錄影照實拍，
  口述補一句「通過後才會搜到其他人的公開貼文」，不要假造別人的貼文。

## 錄影流程

### 0:00–0:20 自我介紹

口述或字幕：

> 這是 DaFeiYu Bot，一個個人、非商業的 AI 角色帳號。今天要示範 `threads_keyword_search` 的用途：找到公開貼文，回覆一則簡短、相關、不推銷的留言。

畫面：顯示 Threads 個人檔案，bio 有寫「AI 角色」。

### 0:20–0:50 發一篇自己的貼文

- 執行 `.\大肥魚.bat post --dry-run`，顯示生成的內容。
- 再執行 `.\大肥魚.bat post`，到 Threads 重新整理，看到貼文與 AI 標籤。

口述：「這是它自己的貼文，一天最多 3 篇。」

### 0:50–1:30 關鍵字搜尋

- 在 App 或 API 工具中執行一次 keyword search（例如 `q=AI`）。
- 畫面顯示搜尋結果，只有公開貼文。
- 口述：「只搜公開貼文，關鍵字限縮在 AI、白飯、摸魚、工程師、桌面寵物。」

### 1:30–2:10 回覆一則公開貼文

- 選一則相關的公開貼文。
- 顯示生成的 1–2 句回覆。
- 實際送出，到 Threads 看到回覆。
- 口述：「一天最多 10 則、同一篇只回一次、間隔至少 30 秒、不推銷、不放連結。」

### 2:10–2:40 安全機制

- 打開 `config.json` 的 `safety.blocked_keywords`。
- 口述：「政治、宗教、災難、醫療、投資、色情、廣告、連結，一律跳過。」
- 示範一則被跳過的留言（或說明 skip 名單）。

### 2:40–3:00 結尾

- 顯示隱私政策網址。
- 口述：「沒有伺服器、不賣資料、可隨時撤銷權限。這是個人興趣專案，不是商業服務。」

## 上傳

- YouTube 設為「不公開」即可，貼連結給 Meta。
- 或直接上傳到 App Review 表單（有大小限制，太大就壓縮）。
