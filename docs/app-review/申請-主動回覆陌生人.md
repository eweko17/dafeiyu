# 申請「主動回覆陌生人」權限

## 先分清楚兩件事

| 想做的事 | 需要什麼 | 現在能不能用 |
|---|---|---|
| 回覆**自己貼文底下**的留言（含留言串裡的下層回覆） | `threads_basic` + `threads_read_replies` + `threads_content_publish` | ✅ 不用審核，現在就能用 |
| 主動去**陌生人的公開貼文**底下回覆 | `threads_keyword_search`（搜公開貼文） | ⏳ 要 Meta App Review |
| 讀别人 @ 到你的貼文 | `threads_manage_mentions` | ⏳ 要 Meta App Review |

Meta 的規定是：`threads_keyword_search` 在審核通過前，**只搜得到你自己的貼文**。
所以現在程式沒有辦法自己找到陌生人的貼文，不是程式壞掉。

---

## 申請前先準備好這 4 樣

Meta 送審時一定會看這些，缺一個就會被退回：

1. **隱私權政策網址（Privacy Policy URL）**
   最省事：在 GitHub Pages 放一頁 `privacy.html`，內容寫明「本 App 只讀取你授權的 Threads 資料、不販售、不分享、可隨時撤銷」。
2. **服務條款網址（Terms of Service URL）**
   可以跟隱私權政策放同一頁，或另一頁。
3. **App 圖示**（1024×1024 PNG）
4. **螢幕錄影（Screencast）**
   30–90 秒，實際操作一次：打開 App → 授權 Threads → 看到它搜尋公開貼文 → 回覆一則 → 顯示回覆成功。
   影片要讓審核員看懂「使用者本人有明確操作，不是機器人亂洗版」。

---

## 送審步驟

1. 打開 <https://developers.facebook.com/apps/>
2. 選你的 App → 左側 **App Review** → **Permissions and features**
3. 找到 **`threads_keyword_search`** → 按 **Request advanced access**
4. 填寫：
   - **用途說明**：見下面範例
   - **Screencast**：上傳上面錄的影片
   - **Privacy Policy URL**、**Terms URL**
5. 按 **Submit for review**
6. 等 Meta 回覆（通常幾天到幾週，免費）

通過後，`threads_keyword_search` 會出現在你的權限清單。這時要**重新產生 Threads token**（授權時勾選新權限），
再把新 token 更新到 GitHub Secrets 的 `THREADS_TOKEN`，程式才拿得到新權限。

> 如果也要讀 @ 提及，重複上面步驟申請 `threads_manage_mentions`。

## 用途說明範例（可直接改）

**中文**

> 這是一個個人使用的 Threads 助手。使用者先在自己的帳號授權後，助手會用 `threads_keyword_search`
> 搜尋與使用者設定主題相關的公開貼文，並只在使用者按下「回覆」時，針對該則貼文送出一則簡短、
> 有禮貌的回覆。助手不會自動大量回覆、不會私訊、不會收集或轉售任何使用者資料。
> 每日回覆數量有上限，且使用者可以隨時在 App 內關閉此功能。

**英文**

> This is a personal Threads assistant. After the user authorizes their own account, the assistant uses
> `threads_keyword_search` to find public posts related to topics the user has configured. A reply is only
> published when the user explicitly taps "Reply" for that specific post. The assistant does not bulk-reply,
> does not send direct messages, and does not collect or sell user data. A daily reply cap is enforced, and
> the user can disable this feature at any time.

## 通過之前，你可以先做什麼

- **回自己貼文底下的留言**：已經可以用，而且會記住每個人（見過幾次、說過什麼、上次回什麼）。
  只要有人來留言，雲端排程每 30 分鐘會自動回。
- **想回特定陌生人的貼文**：目前沒有「手動貼網址」的功能。Threads 的網址不含數字 ID，
  要另外想辦法取得貼文 ID；如果你真的需要，可以再開發一個「手動貼貼文 ID」的指令，
  但這仍然屬於主動回覆，建議等審核通過再大量使用。
- **先把人設、回覆風格、敏感詞規則調好**：審核通過後就能直接上線，不用再等。

---

## 送審會失敗的常見原因

- 隱私權政策網址打不開，或內容跟 App 實際行為不符
- 影片只拍到程式碼或終端機，沒有拍到「使用者操作」
- 用途寫得太籠統（例如「增進互動」），沒有說明具體流程
- App 還是 Development mode 就送出（要先切到 Live）
- 權限要了卻沒有在影片裡實際用到

---

## 提醒

- 就算通過，也不要拿來洗版。Meta 對「大量主動回覆」很敏感，帳號可能被限制。
- 程式內建一天最多 3 篇發文、30 則回覆、同一個人一天最多回 3 次，這些上限不要隨便拿掉。
- 審核結果由 Meta 決定，不是寫了這份文件就會過。
