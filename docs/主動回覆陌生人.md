# 主動回覆陌生人的貼文（`discover`）

> 一句話：程式已經寫好了，但 **Meta 還沒給權限**，所以現在跑會被擋下來。
> 通過 App Review 之後，把 `config.json` 的 `discover.enabled` 改成 `true`，雲端排程就會自己開始。

---

## 現在為什麼不能跑

`discover` 用的是 Threads 的關鍵字搜尋端點 `GET /keyword_search`。Meta 的規定是：

- 沒通過審查 → **只搜得到你自己的貼文**
- 通過 `threads_keyword_search` 進階權限 → 才搜得到公開貼文

而且官方文件也寫：要回覆／引用／轉發公開貼文，前提是「透過搜尋找到它」。
所以**搜尋權限就是整個功能的前提**，沒有它連「你貼連結、牠自動回」都做不到
（API 不吃短網址，短碼也無法換回數字 ID）。

沒權限時跑 `discover` 會看到：

```
Meta 還沒給這個 App「threads_keyword_search」權限。
這是 App Review 的審核項目，不是程式壞掉。
```

程式會直接停下來，**不會退回「亂發」或一直重試**。

---

## 通過審核後，三步驟開啟

1. 到 <https://developers.facebook.com/apps/> → 你的 App → **App Review → Permissions and features**
   確認 `threads_keyword_search` 顯示 **Advanced access / Granted**。
2. 打開 `config.json`，把

   ```json
   "discover": { "enabled": false, ... }
   ```

   改成 `"enabled": true`。
3. 先在本機測一次（不會發出去）：

   ```powershell
   .\大肥魚.bat discover --dry-run --limit 1
   ```

   看得到「`[dry-run] @某人：…` → …」就代表通了。接著真的跑：

   ```powershell
   .\大肥魚.bat discover --limit 1
   ```

之後雲端的 `auto` 每次跑就會順便主動回 1 則（一天最多 3 則）。

---

## 它怎麼挑貼文

依序篩選，任何一項不符合就跳過：

| 條件 | 預設 | 說明 |
|---|---|---|
| 關鍵字 | `白飯`、`摸魚`、`上班好累`、`工程師`、桌面寵物、AI 工具 | 太少會沒東西回，太多會像洗版 |
| 貼文年齡 | 10 分鐘～12 小時 | 太新的怕打擾、太舊的像在挖墳 |
| 字數 | 至少 12 字 | 太短（「哈哈」）沒東西可接 |
| 中文比例 | 至少 6 個中文字 | 英文貼文用中文回很怪 |
| 是不是回覆 | 跳過 | 只回「主貼文」，避免插進別人的對話 |
| 引用貼文 | 跳過 | 避免變成轉發大戰 |
| 黑名單字 | 政治、宗教、投資、醫療、色情、網址、加賴… | 沿用 `safety.blocked_keywords` |
| 同一個人 | 7 天內不再回 | 避免像跟蹤 |
| 已回過 | 跳過 | 記錄在 `state/memory.json` 的 `replied` |

一天上限 3 則、一輪最多 1 則，兩則之間至少隔 45 秒。

## 參數（`config.json` → `discover`）

| 參數 | 預設 | 說明 |
|---|---|---|
| `enabled` | `false` | 總開關；沒過審核前不要開 |
| `keywords` | 6 組 | 要搜的字 |
| `search_type` | `RECENT` | `RECENT` 抓最新，`TOP` 抓熱門 |
| `max_per_day` | `3` | 一天最多主動回幾則 |
| `max_per_run` | `1` | 每 10 分鐘那一輪最多回幾則 |
| `limit` | `25` | 每個關鍵字抓幾篇 |
| `min_age_minutes` | `10` | 貼文至少放多久才回 |
| `max_age_hours` | `12` | 超過幾小時就不回 |
| `min_chars` | `12` | 貼文字數下限 |
| `reply_max_chars` | `50` | 留言長度上限（比回自己留言更短） |
| `same_user_cooldown_days` | `7` | 同一個人幾天內不再回 |
| `min_interval_seconds` | `45` | 兩則之間的間隔 |
| `require_cjk` | `true` | 只回中文貼文 |
| `allow_replies` | `false` | 要不要也回「別人的回覆」 |
| `skip_quote_posts` | `true` | 跳過引用貼文 |

想更保守：`max_per_day` 改 `1`、`keywords` 只留 2 組。
想更活躍（不建議）：一天不要超過 5 則。

## 雲端手動跑一次

GitHub → Actions → **大肥魚排程** → Run workflow，任務選：

- `discover`：真的回一則
- `discover-dry`：只印出來，不發

---

## 安全機制

- 回覆內容會先過 `safety.blocked_keywords`，命中就不發。
- 模型判斷不適合（政治、悲劇、業配、吵架…）會輸出 `SKIP`，程式直接跳過並記錄。
- 每一則都帶 Meta 的 AI 生成標記（`is_made_with_ai`）。
- 對方不高興可以要求停止：把帳號加進 `state/memory.json` 的 `skipped`，或直接在 `blocked_keywords` 加他的名字（比較粗暴但有效）。

---

## 如果之後被限流

`/keyword_search` 每個使用者 24 小時有查詢上限（約 2,200 次，多數情況用不到）。
真的被限流，log 會出現 `code 4` 或 `Application request limit reached`，隔天會自己恢復。
