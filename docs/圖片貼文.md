# 貼文配圖（用大肥魚表情包，不用 AI 產圖）

大肥魚的貼文會變成「圖＋文」，圖片用的是專案內建的**大肥魚表情包**（就是桌寵碎碎念、聊天時出現的那組圖），
不是每次重新 AI 生成。每次最多兩張，也可以只放一張。

圖片檔案放在 `docs/memes/`，透過 GitHub Pages 公開：
`https://eweko17.github.io/dafeiyu/memes/<檔名>.png`

## 一、怎麼運作

```
貼文文字寫好（含主題、心情）
   ↓
拿文字去比對 docs/memes/memes.json 裡每張圖的 tags
   ↓
分數最高的 1～2 張（同分隨機，避免每次都同一張）
   ↓
完全沒有關鍵字命中 → 隨機放 1 張（避免兩張都文不對題）
   ↓
交給 Threads：1 張用 IMAGE、2 張用 CAROUSEL → 發佈
```

- **一張圖**：`media_type=IMAGE`
- **兩張圖**：`media_type=CAROUSEL`（先建兩個子容器 `is_carousel_item=true`，再建家長容器帶 `children`，最後發佈）
- 任何一步失敗，就**自動退回純文字**，不會因此漏發。

不用等產圖、不用第三方產圖服務、也不會有奇怪的畫風跑出來。

## 二、表情包清單（`docs/memes/memes.json`）

每張圖一筆：

```json
{
  "id": "eating-rice",
  "file": "eating-rice.png",
  "source": "吃白飯的大肥魚.png",
  "alt": "大肥魚表情包：躺平扒白飯",
  "desc": "躺平扒白飯，擺爛捱罵也無所謂，適合被吐槽、偷懶、吃白飯自嘲",
  "tags": ["白飯", "吃飯", "餓", "宵夜", "便當", "減肥", "體重", "胖", "偷懶", "擺爛"]
}
```

| 欄位 | 說明 |
|---|---|
| `id` | 內部代號，會記在 `state/memory.json` |
| `file` | `docs/memes/` 裡的實際檔名（ASCII，避免網址出問題） |
| `source` | 原始中文檔名（只供對照，不會用到） |
| `alt` | 圖片的替代文字 |
| `desc` | 這張圖在演什麼（也會當 alt 的後半段） |
| `tags` | 挑圖用的關鍵字；貼文文字、主題、心情只要包含就會加分 |

想加新圖：把 PNG 放進 `docs/memes/`（檔名用英文數字與 `-`），
再到 `memes.json` 的 `items` 加一筆，補 `file`、`desc`、`tags` 就好，程式不用改。

目前共 **30 張**：27 張表情包，加上 3 張桌寵 v0.4.7「吃白飯」玩法的素材
（`bowl-empty` 空碗、`bowl-full` 滿碗、`rice-ball` 飯糰）。後三張是 512×512
透明 PNG，已壓成 384×384 近白底，跟其他表情包同一規格，
適合「開飯／吃完／還想再一碗／帶便當」這類貼文。

## 三、設定（`config.json`）

```json
"images": {
  "enabled": true,
  "mode": "memes",
  "max_per_post": 2,
  "base_url": "https://eweko17.github.io/dafeiyu/memes/",
  "manifest": "docs/memes/memes.json",
  "alt_prefix": "大肥魚表情包："
}
```

| 欄位 | 說明 |
|---|---|
| `enabled` | `false` 就回到純文字貼文 |
| `mode` | `memes`（預設，用表情包）；`pollinations` 是舊的 AI 產圖備用模式 |
| `max_per_post` | 每次最多幾張，程式中上限是 2 |
| `base_url` | 圖片公開網址的前綴（GitHub Pages） |
| `manifest` | 表情包清單路徑（相對於專案根目錄） |
| `alt_prefix` | 圖片替代文字的開頭 |

## 四、怎麼測試

```powershell
.\大肥魚.bat post --dry-run
```

會直接印出挑到的圖（不用等產圖，幾乎立刻）：

```
[表情包] https://eweko17.github.io/dafeiyu/memes/eating-rice.png
[說明] 躺平扒白飯，擺爛捱罵也無所謂，適合被吐槽、偷懶、吃白飯自嘲
[alt] 大肥魚表情包：躺平扒白飯
```

把網址貼到瀏覽器就看得到圖。**dry-run 不會發文。**

想真的發一篇：

```powershell
.\大肥魚.bat post
```

發完 `state/memory.json` 的那篇貼文會多這些欄位：

```json
"image_urls": ["https://eweko17.github.io/dafeiyu/memes/eating-rice.png"],
"image_memes": ["eating-rice"],
"image_url": "https://eweko17.github.io/dafeiyu/memes/eating-rice.png",
"image_scene": "躺平扒白飯，擺爛捱罵也無所謂，適合被吐槽、偷懶、吃白飯自嘲"
```

兩張圖時 `image_urls` / `image_memes` 會有兩筆。

## 五、常見問題

**Q：為什麼不繼續用 AI 產圖？**
AI 產圖每次畫風都不一樣，偶爾還會出現有點嚇人的圖，而且還要等、還會被額度卡。
表情包是固定的圖，風格穩定、不用等、完全免費。

**Q：圖片網址會過期嗎？**
不會。圖片就在這個 repo 的 `docs/memes/`，用 GitHub Pages 提供。
Threads 發佈時會把圖片抓回去自己存一份，所以就算之後改了 repo，已經發出去的貼文圖也不會消失。

**Q：圖片挑得不對怎麼辦？**
調整 `memes.json` 裡那張圖的 `tags`。貼文的文字、主題、心情都會拿來比對，
把貼文常出現的詞加進去就會更容易挑到。

**Q：想暫時不要配圖？**
`config.json` 的 `images.enabled` 設 `false`，或 `max_per_post` 設 `0`。
