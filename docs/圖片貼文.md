# 貼文配圖（免費、不用 key）

大肥魚的貼文現在會自己配一張圖，像一般人用 Threads 一樣「圖＋文」。
圖片是 AI 生成的插圖，會帶 Meta 的 `is_made_with_ai` 標記。

## 一、怎麼運作

```
貼文文字寫好
   ↓
請模型寫一句英文「畫面描述」（例：chubby blue whale napping on a keyboard, office at night）
   ↓
組成 Pollinations 網址 → 自己先抓一次（確認產得出來、也讓它快取）
   ↓
把圖片網址交給 Threads（media_type=IMAGE）→ 發佈
```

任何一步失敗（連不上、額度滿、圖太小），就**自動退回純文字**，不會因此漏發。

## 二、用的是什么服務

[Pollinations](https://pollinations.ai) 的免費產圖 API：

- 不用註冊、不用 API key、不用付錢
- 圖片網址就是 `https://image.pollinations.ai/prompt/<描述>?width=...&seed=...`
- Threads 會自己去抓那個網址，所以**不需要上傳檔案、不需要圖床**
- 同一個網址會回同一張圖（有快取），所以每次都用隨機 `seed` 產生新圖

### 免費版的限制（先知道，才不會以為壞掉）

| 限制 | 實際影響 |
|---|---|
| 每個 IP **至少 45 秒**才能產一張 | 一次發文只產一張，沒問題；短時間重試會遇到 `402` → 直接改純文字 |
| 圖片面積上限 **768×768** | 4:5 的圖實際約 **686×858**，不是 1080×1350（`config` 寫 1080×1350 也一樣，服務會等比例縮） |
| 角落有小小 `pollinations.ai` logo | 免費版去不掉（`nologo=true` 已無效）；有自己的 key 才能移除 |
| 盡力而為，沒有 uptime 保證 | 產圖失敗就純文字，不影響發文 |

> 想要「無 logo＋高解析度」只能到 <https://enter.pollinations.ai> 自己申請 key（有免費額度）。
> 目前刻意不這樣做，維持「完全免費、不用註冊」。

## 三、設定（`config.json`）

```json
"images": {
  "enabled": true,
  "width": 1080,
  "height": 1350,
  "model": "flux",
  "style": "2d illustration, cute, soft pastel colors, clean simple background, chibi anime girl with long blue hair, wearing a dark blue and white maid dress with a whale apron, no text, no letters",
  "max_attempts": 3,
  "fetch_timeout_seconds": 120,
  "min_bytes": 15000,
  "alt_prefix": "大肥魚插圖："
}
```

| 欄位 | 說明 |
|---|---|
| `enabled` | `false` 就回到純文字貼文 |
| `width` / `height` | 想要的尺寸；免費版會等比例縮到面積上限 |
| `model` | 免費版只有一個模型，這個值加好玩的 |
| `style` | 固定風格，會接在每句畫面描述前面 |
| `max_attempts` | 最多試幾次（遇到 `402` 會直接放棄，不連打） |
| `min_bytes` | 小於這個大小視為失敗（避免抓到錯誤頁） |
| `alt_prefix` | 圖片替代文字的開頭，後面接貼文主題 |

想換畫風就改 `style`（例如 `watercolor`、`pixel art`、`3d render`）。
想關掉就設 `"enabled": false`。

## 四、怎麼測試

```powershell
.\大肥魚.bat post --dry-run
```

會先產一張圖（大約 30–60 秒），然後印出：

```
[插圖] https://image.pollinations.ai/prompt/...
[畫面] chubby blue whale watching cat video, meeting room, soft desk lamp
[alt] 大肥魚插圖：開會時靈魂出竅
```

把 `[插圖]` 的網址貼到瀏覽器就看得到圖。**dry-run 不會發文**。

想真的發一篇：

```powershell
.\大肥魚.bat post
```

發完在 `state/memory.json` 的那篇貼文會多兩個欄位：

```json
"image_url": "https://image.pollinations.ai/prompt/...",
"image_scene": "chubby blue whale watching cat video, meeting room, soft desk lamp"
```

## 五、常見問題

**Q：圖片看起來不像「鯨魚女僕」？**
預設的 `style` 是照大頭貼（藍髮、深藍白女僕裝、鯨魚圍裙）描述，實測最接近。
免費模型對細節還是會漂：有時頭髮變短、圍裙圖案不見、場景物品少一兩樣，這都正常。
想更穩定可以再往 `style` 加描述（例如 `whale tail`、`frilled headband`），但每次仍會有些差異。

**Q：圖片突然都是純文字？**
看 log 有沒有 `Pollinations 免費額度被佔用（402）`。那是同一個 IP 太短時間內產太多張，
等一分鐘下一輪就會恢復。GitHub Actions 是共用 IP，偶爾會被別人佔用，屬正常。

**Q：圖片的網址會過期嗎？**
Threads 發佈時會把圖片抓回去自己存，所以貼文上的圖不會因為 Pollinations 怎麼了而消失。

**Q：隱私上有差嗎？**
只有一句英文畫面描述會送到 Pollinations，內容是「鯨魚在做什麼」，不含任何人的帳號或留言。
隱私政策已補上這一段。
