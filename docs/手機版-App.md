# 手機版大肥魚（聊天 App）

> 一句話：手機打開網址就能跟大肥魚聊天、講話；想更像 App，可以「加到主畫面」或直接安裝 APK。

---

## 網址

| 用途 | 位置 |
|---|---|
| 聊天本體 | <https://eweko17.github.io/dafeiyu/app/> |
| 短網址（會自動跳轉） | <https://eweko17.github.io/> |
| APK | **不在 GitHub**，放在自己的 OneDrive（見下方） |

網頁是公開的，但沒有你的 Groq Key 就不能用，也看不到你的聊天記錄。

> **為什麼 APK 不在 GitHub？**
> 這個 repo 是公開的（免費 GitHub Actions 與 Pages 的必要條件）。
> APK 放上去等於任何人都能下載，所以改成只放在自己的 OneDrive，只有自己能拿。

## 第一次使用

1. 用手機的 Chrome 打開 <https://eweko17.github.io/dafeiyu/app/>。
2. 貼上你的 Groq API Key（`gsk_` 開頭那一串），按「開始聊天」。
   - 只會存在**這支手機的瀏覽器**裡，不會上傳到任何地方。
   - 還沒有 key 的話，畫面上有「到這裡免費拿一把」的連結。
3. 第一次按 🎤 時，瀏覽器會問麥克風權限，選「允許」。
4. 右上角 ⚙️ 可以調：
   - 模型（建議留「自動挑選」）
   - 用語音唸出來
   - 主動找你講話

---

## 三種用法，選一種就好

| 方式 | 怎麼做 | 差別 |
|---|---|---|
| **瀏覽器** | 直接開網址 | 最簡單，但每次都要找分頁 |
| **加到主畫面（PWA）** | Chrome 右上角 ⋮ →「安裝應用程式」或「加到主畫面」 | 桌面有圖示、全螢幕、開啟速度快 |
| **APK** | 下載 `dafeiyu.apk` 安裝 | 真正的 App 圖示，跟一般 App 一樣 |

三種用的是**同一個網站、同一份程式**，所以聊天記錄不會互通（記錄存在各自的瀏覽器空間）。

## 安裝 APK（從自己的 OneDrive）

APK 檔案在電腦的這個位置，OneDrive 會自動同步上去：

```
OneDrive\桌面\大肥魚\apk\dafeiyu.apk
```

手機拿法：

1. 手機打開 **OneDrive** App。
2. 依序點：`檔案` → `桌面` → `大肥魚` → `apk` → `dafeiyu.apk`。
3. 下載後點開，Android 會問「允許安裝未知的應用程式」，選允許。
4. 安裝完成，桌面會出現「大肥魚」。

> 如果 OneDrive 裡看不到「桌面」資料夾，代表這台電腦的桌面沒有備份到 OneDrive。
> 那就用傳輸線、Google Drive、或 LINE 傳給自己，效果一樣。

需求：

- Android 7.0 以上（`minSdk 24`）
- 手機裡要有 **Chrome**（APK 是「信任的網頁活動」，用 Chrome 當引擎；沒有 Chrome 會退回一般瀏覽器）

> 這個 APK 沒有上架 Google Play，所以 Android 會顯示「不明來源」警告，這是正常的。

## 她現在會做什麼

| 功能 | 說明 |
|---|---|
| 聊天 | Groq 串流回覆，打字時會一段一段跑出來 |
| 語音輸入 | 按 🎤 講話，講完自動送出（瀏覽器要支援 Web Speech） |
| 語音朗讀 | 開啟後，她會用台灣中文唸出回覆 |
| 記憶 | 記住最近 300 則訊息，並定期把重點濃縮成「長期記憶」 |
| 主動訊息 | 剛打開、閒置 4～10 分鐘、隔很久回來，她會自己講話 |
| 清空記憶 | 設定 →「清空記憶」，清掉就認不得你了 |

---

## 記憶存在哪裡

- 存在手機瀏覽器的 `localStorage`（key 是 `dafeiyu.v1`）。
- **不會上傳**，也不會跟雲端發文那套的 `state/memory.json` 共用。
- 換手機、換瀏覽器、清網站資料，記憶就會消失。
- 想備份的話，目前沒有做匯出功能，之後可以加。

---

## 主動訊息的限制（重要）

她現在的主動訊息，**只有在 App 開著（前景）的時候才會發生**。

原因是：真正的「關掉 App 也會跳通知」需要 Google 的 Firebase（FCM）推播，那要另外申請一個 Firebase 專案、放 `google-services.json`、再重打 APK。目前沒有做，是因為想先讓你確認整體感覺對不對。

如果你覺得「她會自己找我」這件事很重要，下一步可以加：

1. Firebase 專案（免費）
2. 一個小型的推播排程（GitHub Actions 也能做）
3. 重打一次 APK

## APK 的簽章金鑰（要留好）

| 檔案 | 位置 |
|---|---|
| 金鑰 | `apk\簽章金鑰\signing.keystore` |
| 密碼與別名 | `apk\簽章金鑰\signing-key-info.txt` |
| 網站驗證檔 | `apk\簽章金鑰\assetlinks.json` |

- 這三個檔案**沒有**進公開 repo（`.gitignore` 已排除）。
- 以後要更新 APK，**一定要用同一把金鑰**，不然手機會說「簽章不同」而拒絕更新，只能先移除再裝。
- 金鑰弄丟不影響現在使用，只是以後不能用同一個 App 身分更新。

## 改了程式之後要重打 APK 嗎？

**不用。**

APK 只是一層殼，打開後載入的是
<https://eweko17.github.io/dafeiyu/app/>。
所以：

| 你改了什麼 | 要做什麼 |
|---|---|
| 聊天介面、人設、說話方式 | 改 `docs/app/` → push，手機重新打開就是新的 |
| App 名稱、圖示、package id | 才需要重打 APK |

## 常見問題

**Q：開啟後一直說「這把鑰匙好像不對喔」**
A：key 貼錯或已失效。到 <https://console.groq.com/keys> 重新建一把，貼在設定裡。

**Q：🎤 按了沒反應**
A：iPhone 的 Safari 不支援語音輸入；Android Chrome 可以。另外網址必須是 `https://`（我們是）。

**Q：她都不主動講話**
A：設定裡「主動找你講話」要打開，而且 App 要開著。她最短 4 分鐘、最長 10 分鐘才會自己冒出一句。

**Q：可以兩個人一起用嗎**
A：可以，但每個人的手機要各自貼一次 key，記憶也各自獨立。
