# 設定步驟（約 10 分鐘）

這份文件帶你拿到 **Threads access token**，讓大肥魚可以用你的帳號發文。

> 全程免費。不需要信用卡、不需要架網站、不需要寫程式。
> Token 等於帳號的發文權限，**不要貼給任何人**（包括我）。

---

## 事前準備

1. **一個新的 Threads 帳號**（建議）
   - 可以只用 email 註冊，不一定要 Instagram。
   - 到 Threads → 設定 → 隱私 → 把個人檔案設為**公開**。
   - 帳號簡介建議寫：「一隻 AI 鯨魚女僕，主人是 ___。會吃白飯。」
2. **一個 Meta 開發者帳號**
   - 到 https://developers.facebook.com 用 Facebook 帳號登入，按「開始使用」。
3. 這個資料夾已經跑過 `install.ps1`。

---

## 步驟 1–6：建立 Meta App

1. 開啟 https://developers.facebook.com/apps
2. 右上角 **Create App**
3. 填寫：
   - App name：例如 `DaFeiYu Bot`
   - App contact email：你的信箱
4. **Add use cases** 頁面，勾選 **Access the Threads API** → Next
5. Business portfolio：選 **I don't want to connect a business portfolio yet** → Next
6. 確認頁面顯示 **No requirements identified** → Next → **Create app**

---

## 步驟 7–12：把 Threads 帳號加為測試人員

7. App 後台左側點 **Use cases**
8. 找到 **Access the Threads API** → 點 **Customize**
9. 左側點 **Settings**
10. 往下找到 **User Token Generator** → 點 **Add or Remove Threads Testers**
11. 右上角 **Add People**
12. 選擇 **Threads Tester** → 搜尋你的 Threads 帳號 → **Add**

> 如果搜不到帳號：
> - 確認 Threads 個人檔案是公開的
> - 確認該帳號已經有 Meta 開發者帳號（用同一個 email 登入 developers.facebook.com）
> - 帳號剛辦好時，等幾分鐘再試

---

## 步驟 13–14：到 Threads 接受邀請

13. 用**那隻要大肥魚發文的 Threads 帳號**登入 https://www.threads.com
14. 右上角 **More** → **Settings** → **Website permissions** → **Invites** 分頁
    - 找到剛剛的 App（例如 `DaFeiYu Bot`）→ **Accept**

---

## 步驟 15–18：產生 Token

15. 回到 Meta App 後台 → **Use cases** → **Access the Threads API** → **Customize** → **Settings**
16. 在 **User Token Generator** 區塊找到你的帳號 → **Generate Access Token**
17. 授權頁確認帳號正確 → 勾選以下權限 → **Continue as …**

    - ✅ `threads_basic`
    - ✅ `threads_content_publish`
    - ✅ `threads_read_replies`
    - ✅ `threads_manage_replies`
    - ✅ `threads_manage_insights`（可選，但建議）

18. 回到後台，勾選 **I understand** → **Copy** 複製整串 token

> Token 有效 60 天。我們的排程每週日會自動續期，所以只要筆電有開著，就不會過期。

---

## 貼進大肥魚

回到資料夾，執行：

```powershell
.\大肥魚.bat setup
```

貼上 token → Enter。程式會：

1. 呼叫 `/me` 驗證 token
2. 顯示 `@你的帳號`
3. 問你是否確定
4. 把 token 與 user id 存到 `state/secrets.json`

接著跑健康檢查：

```powershell
.\大肥魚.bat doctor
```

看到 `Threads 帳號 OK`、`Ollama OK` 就完成了。

---

## 可選：Gemini 備援

如果 Ollama 掛掉或太慢，可以自動換成 Gemini 免費額度。

1. 開啟 https://aistudio.google.com/apikey
2. 用 Google 帳號登入 → **Create API key**
3. 複製 key
4. 執行 `.\大肥魚.bat setup` 時貼在「Gemini API key」欄位（或直接寫進 `state/secrets.json` 的 `gemini_api_key`）

> 免費層的限制：每分鐘約 15 次、每天約 1,000–1,500 次，對一天 3 篇來說非常夠。
> 代價：免費層的內容會被 Google 用於改進服務。介意就不要填，只用本機 Ollama。

## 常見錯誤

| 錯誤 | 原因 | 解法 |
|---|---|---|
| `Token 驗證失敗` | token 複製不完整、過期、或帳號沒接受邀請 | 重新產生一次 token；確認 Threads → Website permissions 已 Accept |
| `(#10) Application does not have permission` | 權限沒勾、或不是測試人員 | 回步驟 12 確認角色；回步驟 17 確認五個權限都勾 |
| `Object does not exist` | user id 錯、或 token 屬於別的帳號 | 重新執行 `setup`，讓程式用 `/me` 重新抓 id |
| `連不到 Ollama` | Ollama 沒開、或安裝失敗 | 開 Ollama 應用程式；或 `ollama serve` |
| `找不到模型 qwen2.5:7b-instruct` | 模型沒下載完 | `ollama pull qwen2.5:7b-instruct` |
| 發文成功但 Threads 上沒看到 | 快取或帳號看錯 | 用無痕模式開 `threads.com/@你的帳號` |

## 安全提醒

- `state/secrets.json` 存著 token，等於帳號鑰匙。不要截圖、不要上傳、不要放進 Git。
- 這個資料夾在 OneDrive 裡，`secrets.json` 會同步到雲端。如果你不放心：
  - 把 `state/` 移到 `C:\Users\user\AppData\Local\DaFeiYu\`，並修改 `app/paths.py`，或
  - 把 token 當消耗品，每 60 天換一次。
- 想撤銷權限：Threads → Settings → Website permissions → 移除 App。
