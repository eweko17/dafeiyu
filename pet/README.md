# 桌寵（dsh-pet）

這是社群版 `dsh-pet` v0.4.1 Windows x64 獨立版，解壓即用，**不需要 DSH、不需要 Node、不需要管理員權限**。
本機這一份已經**改成全繁體中文介面**，角色採用內建的「吃白飯的藍色大肥魚」，並把名字設為「大肥魚」。

## 啟動／關閉

| 動作 | 方法 |
|---|---|
| 啟動 | 雙擊 `啟動桌寵.bat`（或直接執行 `dsh-pet-win-x64\dsh-pet-0.4.1-win-x64\dsh-pet.exe`） |
| 關閉 | 雙擊 `關閉桌寵.bat`，或系統匣圖示按右鍵 →「結束」 |
| 不想每次開機都看到她 | 把她從「啟動」資料夾移除（見下方說明） |

- 重複執行 `dsh-pet.exe` 不會開第二隻（單一實例），只會把原本那隻叫出來。
- 工作列右下角（系統匣）會有她的圖示，圖示右鍵就是主要的控制選單。

## 怎麼玩

- **拖曳**：按住她可以拖到螢幕任何位置。
- **點擊**：會播反應動畫（揮手、害羞、生氣、被搔癢…）。
- **右鍵**：開啟功能選單（查看餘額、待辦事項、碎碎念、對話、配圖、睡覺／起來、動作動畫、顯示位置、重新載入設定、回到初始位置）。
- 桌面寵物視窗要先點她一下、拿到鍵盤焦點，快捷鍵才會生效。

## 她現在在哪裡

出廠預設是「右下角」，但這台電腦的 DPI 偵測會逾時（log 會看到 `dpi probe failed`），導致她一開始會被推到螢幕外。
所以已把位置調成「右下角、離右邊 220px、離下面 140px」，畫面上看得到完整一隻。
想改位置有兩個方法：

1. 直接把她拖到想要的位置（拖曳後會自己記住）。
2. 改 `dsh-pet-win-x64\dsh-pet-0.4.1-win-x64\resources\app\assets\config.jsonc` 裡的
   `"position": { "corner": "bottom-right", "marginX": 220, "marginY": 140 }`，存檔後右鍵 →「重新載入設定」。

`corner` 可填 `top-left` / `top-right` / `bottom-left` / `bottom-right`。

## 繁體化做了什麼

`dsh-pet` 介面文字是寫死在程式裡的（沒有語言切換），所以是把打包檔 `app.asar` 解開後逐檔轉成繁體：

- `app.asar` 已解包成 `resources\app\` 資料夾（Electron 會優先用資料夾，再來才是 asar）。
- 介面文字、對話面板、設定頁、系統匣、氣泡文案、`config.jsonc` 的人設與說明全部轉成繁體（台灣用語）。
- **109 段動畫與 27 張表情包的檔名也一起轉成繁體**，並同步改好所有參照，所以動畫與表情包都能正常播放。
- 原本簡體的 `app.asar` 備份在 `resources\app.asar.bak`。

### 想還原成簡體版

1. 關閉桌寵。
2. 把 `resources\app` 資料夾改名（例如 `app_backup`）。
3. 把 `resources\app.asar.bak` 改名回 `app.asar`。
4. 重新啟動桌寵。

> 注意：`%APPDATA%\dsh-pet\main-config.jsonc` 是「使用者設定」。如果你在設定頁按過「儲存」，裡面會寫一份設定，
> 之後改 `resources\app\assets\config.jsonc` 就不會生效。要改回預設值，把 `main-config.jsonc` 刪掉即可。

## 她的大腦（可選）

桌寵本身可以接 AI（碎碎念與對話）。目前**沒有**幫她接上本機的 Ollama，所以碎碎念只會說內建台詞。
想讓她用本機模型說話：系統匣圖示 →「開啟 AI 設定」→ 服務商選 OpenAI 相容 → 網址填
`http://127.0.0.1:11434/v1`、模型填 `qwen2.5:7b-instruct`（金鑰隨便填一個非空字串）。

> 提醒：這樣她說話時會跟大肥魚發文程式搶同一份記憶體，建議二選一，或改用 `qwen2.5:3b-instruct`。

## 記憶體

- 待機時大約 **300–400 MB**（實測 355 MB，Electron 主程序＋算圖程序），關掉就是 0。
- 她只有在碎碎念／對話時才會呼叫模型；本機 Ollama 模型會在閒置 2 分鐘後自動卸載（見專案 `config.json` 的 `keep_alive`）。
- 這台電腦（i5-1235U / 15.7 GB）平常還有 5 GB 以上可用，開著她不會影響上網、文書。

## 不要她每次開機都出現

她沒有註冊成開機啟動項目，只有你雙擊才會出現。若你曾把她放進「啟動」資料夾，到
`shell:startup`（Win+R 輸入）把捷徑刪掉即可。

## 移除

先關閉桌寵，再刪掉整個 `pet\dsh-pet-win-x64` 資料夾與 `%APPDATA%\dsh-pet\`、`%USERPROFILE%\.dsh\dsh-pet\`，不會殘留系統設定。
